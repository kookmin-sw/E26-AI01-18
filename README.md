## 9/18 활동 내역
자율주행자동차
일부 실현
운전자 없이 스스로 주행하는 기술이 개발되어 실제 무인 택시 서비스에도 사용되고 있지만, 아직 모든 지역에서 보편적으로 이용되지는 않고 있다. 

로봇청소기
실현됨
로봇이 스스로 집 안을 이동하며 청소하고, 장애물을 피하거나 자동으로 충전하는 기능까지 구현되어 일상에서 사용되고 있다. 

하늘을 나는 자동차
일부 실현
도로 주행과 비행이 가능한 자동차가 실제로 개발되고 시험 비행도 이루어졌지만, 아직 일반적인 교통수단으로 상용화되지는 않았다. 

화상통화
실현됨
멀리 떨어진 사람과 화면을 통해 얼굴을 보며 대화하는 기술은 스마트폰과 인터넷을 통해 일상적으로 사용되고 있다.

원격 수업
실현됨
인터넷과 화상회의 프로그램을 이용해 장소에 관계없이 실시간으로 수업을 듣고 화면이나 자료를 공유할 수 있게 되었다. 

소감
소감 과거에 상상하던 기술들이 실제 생활 속에서 하나씩 실현되고 있다는 점이 신기했다. 특히 벽면 전체가 유리 패널로 되어 있어 멀리 떨어진 공간인데도 마치 옆방에 있는 것처럼 느껴지게 하는 기술이 가장 인상 깊었다.
